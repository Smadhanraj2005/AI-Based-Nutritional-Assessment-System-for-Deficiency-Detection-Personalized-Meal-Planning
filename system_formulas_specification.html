System Formulas Specification Manual

AI-Based Nutritional Assessment System for Deficiency Detection & Personalized Meal Planning

1. Dietary Diary & Nutrient Intake Aggregation Formulas

1.1 Portion Gram Scale Factor

$$\text{Scale Factor} = \frac{\text{portion\_grams}}{100.0}$$

1.2 Item Nutrient Intake Calculation

$$\text{Nutrient}_{\text{item}, k} = \text{Nutrient}_{\text{stored per 100g}, k} \times \text{Scale Factor}$$

1.3 Daily Total Intake per Nutrient (on date $d$)

$$\text{Daily Total}(k, d) = \sum_{i \in \text{Items logged on } d} \text{Nutrient}_{i, k}$$

1.4 Multi-Day Daily Average Intake

$$\text{Daily Average}(k) = \frac{\sum_{d \in D} \text{Daily Total}(k, d)}{N_{\text{distinct days}}} \quad \text{where } N_{\text{distinct days}} = \max(1, |D|)$$

1.5 Vitamin D Unit Conversion

$$\text{Vitamin D (mcg)} = \frac{\text{Vitamin D (IU)}}{40.0}, \quad \text{Vitamin D (IU)} = \text{Vitamin D (mcg)} \times 40.0$$

2. Recommended Dietary Allowance (% RDA) Formulas

2.1 Percentage of RDA (% RDA)

$$\% \text{RDA}(k) = \operatorname{round}\left( \frac{\text{Daily Average}(k)}{\text{RDA Target}(k)} \times 100.0, 1 \right)$$

3. Machine Learning Input Feature Encoding & Inference

3.1 Gender Categorical Encoding

$$\text{gender\_num} = \begin{cases} 1.0 & \text{if Gender } \in \{\text{"Male"}, \text{"1"}, \text{"m"}\} \\ 2.0 & \text{if Gender } \in \{\text{"Female"}, \text{"2"}, \text{"f"}\} \end{cases}$$

3.2 Standard Feature Normalization (StandardScaler)

$$X_{\text{scaled}, j} = \frac{X_j - \mu_j}{\sigma_j}$$

3.3 13-Feature Input Vector Order

$$X_{\text{input}} = [\text{gender}, \text{age\_years}, \text{calories\_kcal}, \text{protein\_g}, \text{iron\_mg}, \text{calcium\_mg}, \text{vitamin\_d\_mcg}, \text{vitamin\_b12\_mcg}, \text{folate\_mcg}, \text{vitamin\_a\_mcg}, \text{vitamin\_c\_mg}, \text{magnesium\_mg}, \text{zinc\_mg}]$$

3.4 Multi-Output Random Forest Ensemble Probability Inference

$$P_{\text{raw}}(\text{Deficiency}_k = 1 \mid X) = \frac{1}{T} \sum_{t=1}^{T} P_t(\text{Deficiency}_k = 1 \mid X_{\text{scaled}})$$

4. Clinical RDA Intake Calibration Rules

Let $\text{Ratio}_k = \frac{\text{Daily Average}(k)}{\text{RDA Target}(k)}$:

$$P_{\text{calibrated}}(k) = \begin{cases} \min(P_{\text{raw}}(k), 0.15) & \text{if } \text{Ratio}_k \ge 1.0 \quad (100\%+\text{ RDA met}) \\ \min(P_{\text{raw}}(k), 0.38) & \text{if } 0.70 \le \text{Ratio}_k < 1.0 \quad (70-99\%\text{ RDA met}) \\ \max(P_{\text{raw}}(k), 0.38) & \text{if } 0.40 \le \text{Ratio}_k < 0.70 \quad (40-69\%\text{ RDA met}) \\ \max(P_{\text{raw}}(k), 0.48) & \text{if } \text{Ratio}_k < 0.40 \quad (<40\%\text{ RDA met}) \end{cases}$$

5. Post-Prediction Clinical Laboratory Boost Rules

5.1 Hemoglobin Clinical Boost (Anemia)

$$\text{Hb Threshold} = \begin{cases} 12.0\text{ g/dL} & \text{if Female} \\ 13.0\text{ g/dL} & \text{if Male} \end{cases}$$ $$\text{if } \text{Hemoglobin} < \text{Hb Threshold} \implies P_{\text{final}}(\text{Iron}) = \max(P_{\text{calibrated}}(\text{Iron}), 0.75)$$

5.2 Ferritin & Serum Iron Clinical Boosts

$$\text{if } \text{Ferritin} < 30.0\text{ ng/mL} \implies P_{\text{final}}(\text{Iron}) = \max(P_{\text{calibrated}}(\text{Iron}), 0.70)$$ $$\text{if } \text{Serum Iron} < 30.0\text{ mcg/dL} \implies P_{\text{final}}(\text{Iron}) = \max(P_{\text{calibrated}}(\text{Iron}), 0.70)$$

5.3 Serum Vitamin D, B12 & Calcium Boosts

$$\text{if } \text{Serum Vit D} < 50.0\text{ ng/mL} \implies P_{\text{final}}(\text{Vit D}) = \max(P_{\text{calibrated}}(\text{Vit D}), 0.65)$$ $$\text{if } \text{Vit B12} < 200.0\text{ pg/mL} \implies P_{\text{final}}(\text{Vit B12}) = \max(P_{\text{calibrated}}(\text{Vit B12}), 0.60)$$ $$\text{if } \text{Calcium} < 8.5\text{ mg/dL} \implies P_{\text{final}}(\text{Calcium}) = \max(P_{\text{calibrated}}(\text{Calcium}), 0.55)$$

6. Overall Wellness Score & Risk Classification Formulas

6.1 Mean Deficiency Risk ($\bar{R}$)

$$\bar{R} = \frac{1}{10} \sum_{k=1}^{10} P_{\text{final}}(\text{Deficiency}_k)$$

6.2 Overall Health / Wellness Score

$$\text{Wellness Score} = \operatorname{clamp}\left( \operatorname{round}\left( (1.0 - \bar{R}) \times 100.0, 1 \right), 0.0, 100.0 \right)$$

6.3 Risk Level Banding Classification

$$\text{Risk Level}(P) = \begin{cases} \text{HIGH} & \text{if } P \ge 0.66 \\ \text{MODERATE} & \text{if } 0.35 \le P < 0.66 \\ \text{LOW} & \text{if } P < 0.35 \end{cases}$$

7. Recommended Foods Ranking & Search Formulas

7.1 Catalog Ranking Order

$$\text{ORDER BY } \text{source\_priority ASC}, \text{nutrient\_column DESC}$$ $$\text{where } \text{source\_priority} = \begin{cases} 0 & \text{Curated Indian Foods (\text{data/seed\_foods.json})} \\ 1 & \text{IFCT 2017 Dataset (~542 NIN Hyderabad Foods)} \\ 2 & \text{USDA FoodData Central Fallback} \end{cases}$$

7.2 Candidate Fetch Pool Size

$$N_{\text{candidates}} = \max(\text{limit} \times 8, 48)$$

7.3 Setup Progress Ring Percentage & Stroke Dash

$$\text{Setup Percentage} = \left( \frac{\sum_{m=1}^{4} \mathbb{I}(\text{Step}_m \text{ complete})}{4} \right) \times 100$$ $$\text{SVG Fill Offset} = (2 \pi \cdot 28) \times \left( \frac{\text{Setup Percentage}}{100} \right)$$
